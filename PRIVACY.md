## Privacy Policy

This Privacy Policy describes how this repository's tools (the "Software") handle data when you use them to access the YouTube API Services.

## 1. Data We Access and Collect

* API Authentication: The Software requires a YouTube API key or OAuth 2.0 credentials provided by you. These credentials are stored strictly on your local machine and are never transmitted to the developer or any third party.
* YouTube Data: The Software requests publicly available YouTube data (such as video metadata, channel stats, and comments).
* No Server Storage: We do not own external servers. All fetched YouTube data is processed and stored locally on your own computer. We do not collect, store, or track your personal information or search history.

## 2. How Data is Used

* Data fetched via the YouTube API is used solely to perform the local analysis and functions requested by you within the execution environment.
* We do not share, sell, or use your data for advertising.

## 3. Third-Party Services

By using these tools, you are accessing YouTube API Services. You agree to be bound by the following third-party terms:

* YouTube Terms of Service: [youtube.com](https://www.youtube.com/t/terms)
* Google Privacy Policy: [google.com](https://policies.google.com/privacy)

You can revoke the Software's access to your data at any time via the [Google Security Settings page](https://myaccount.google.com/permissions).

## 4. Contact and Deletion

Since all data remains on your local machine, you can delete all collected data at any time simply by deleting the local output files (e.g., CSVs, JSONs, or databases) generated by the tools. For questions about this policy, please open an Issue in this GitHub repository.
